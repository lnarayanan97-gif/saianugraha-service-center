# Sai Anugraha Service Center Website

Starter premium website for saianugrahakovai.in.

## Files
- `index.html` - Home page
- `css/style.css` - Design and responsive layout
- `js/script.js` - Menu and starter form interaction
- `images/logo.png` - Uploaded Sai Anugraha logo

## Before publishing
Replace the placeholders in `index.html`:
- Phone / WhatsApp number
- Email
- Full address
- Service areas
- Final business description

Then connect the booking form to WhatsApp, Formspree, a backend, or another form service.

## GitHub Pages
Upload the project files to your GitHub repository, enable GitHub Pages from the repository settings, then point `saianugrahakovai.in` to the GitHub Pages custom domain.
